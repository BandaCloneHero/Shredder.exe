# Nome do jogo
Shredder.exe 

# Premissa
Jogo de ritmo com até 4 jogadores, incluindo controles de guitarra, baixo, teclado e bateria.

# Universo do Jogo
No ano de 2167, quase todas as músicas são feitas por grandes corporações de I.A. O jogador é parte de uma das poucas bandas humanas que quer se manter relevante, mas para isso, deve provar sua habilidade no contesto de bandas.
